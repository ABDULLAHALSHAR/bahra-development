# Bahra Electric LMS — Premium Edition 2026

نسخة مطورة من منصة بحرة إلكتريك للتدريب والتطوير.

## أهم التطويرات
- تصميم Premium للواجهة الرئيسية، البطاقات، صفحات الدورات ومسار التعلم.
- صفحة دورة أكثر وضوحًا مع التقدم، الدروس، الاختبار وحالة الموظف.
- تدفق إصدار الشهادة: إكمال الدروس → اجتياز الاختبار 70% → تقييم الدورة → إصدار الشهادة.
- شهادة احترافية A4 Landscape تشمل:
  - شعار وهوية Bahra Electric
  - اسم الموظف واسم الدورة
  - عدد الساعات ونتيجة الاختبار
  - تاريخ الإصدار ورقم شهادة فريد
  - رمز تحقق Verification Code
  - QR للتحقق عند تشغيل المنصة أونلاين
  - توقيع مدير الموارد البشرية
- طباعة الشهادة أو حفظها PDF من المتصفح.
- Backend مطور لإنشاء تبويب certificates تلقائيًا في Google Sheets وحفظ الشهادات والتحقق منها.

## الملفات
- `index.html` — المنصة المطورة كاملة.
- `backend/Code.gs` — Apps Script المطور.
- `data/platform_data.xlsx` — نسخة من ملف البيانات المرسل.

## التشغيل السريع
1. ارفع `index.html` على GitHub Pages مكان الملف السابق.
2. من Google Sheets افتح Extensions > Apps Script واستبدل Code.gs بالنسخة الموجودة في `backend/Code.gs`.
3. Deploy > New deployment > Web app.
4. انسخ رابط `/exec` وضعه في `CONFIG.API_URL` داخل `index.html`.
5. عند أول شهادة يتم إصدارها، ينشئ Apps Script تبويب `certificates` تلقائيًا ويحفظ الشهادات فيه.

## ملاحظة QR
الـ QR يعمل بأفضل شكل عند تشغيل المنصة عبر رابط GitHub Pages. عند استخدام المنصة بدون إنترنت، تبقى الشهادة ورمز التحقق محفوظين محليًا، بينما صورة QR تحتاج اتصالًا لعرضها.
