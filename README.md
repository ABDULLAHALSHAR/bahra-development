# منصة بحرة إلكتريك لتطوير الموظفين
**Bahra Electric — Employee Development Platform (LMS)**

منصة تعلّم متكاملة: الموظف يدرس محتوى الدورة، يحل الاختبار، ويحصل على شهادة تلقائياً؛ والمدير يعتمد الطلبات ويدير المحتوى — بواجهة عربية/إنجليزية (RTL) ووضع فاتح/داكن.

## التشغيل
- محلياً: افتح `index.html` بأي متصفح — يعمل بالكامل **بدون إنترنت** (ملف واحد، الصور مدمجة).
- أونلاين: ارفعه على GitHub Pages (خطوات في `backend/دليل_النشر_والربط.md`).
- **يحفظ تقدّمك** (الدروس، الاختبارات، الشهادات) تلقائياً في المتصفح.

## أهم المزايا
- رحلة تعلّم كاملة: طلب التحاق ← اعتماد المدير ← تسجيل تلقائي ← دراسة الدروس ← اختبار نهائي ← إصدار شهادة.
- محتوى دراسي حقيقي لكل الدورات الـ 12 (دروس + نقاط رئيسية + اختبار 5 أسئلة لكل دورة).
- شهادات قابلة للطباعة/حفظ PDF بهوية بحرة، برقم شهادة ودرجة وتاريخ.
- إدارة محتوى للمدير/المدرب: إضافة دورات ودروس وأسئلة اختبار.
- اعتماد الطلبات يسجّل الموظف بالدورة مباشرة.
- محرك الاحتياج التدريبي بأولوية: إلزامي ← أداء ← مهارات ← اختبارات.
- 50 موظف / 3 أدوار / تقارير وتحليلات أثر، ومساعد «اسألني» (محلي + Groq اختياري).

## الملفات
```
index.html                     المنصة كاملة (ملف واحد مكتفٍ ذاتياً)
.nojekyll                      لعرض الملف كما هو على GitHub Pages
data/بيانات_المنصة.xlsx        بيانات الموظفين والدورات (Excel)
backend/Code.gs                باك-إند Apps Script (Groq + Google Sheets)
backend/دليل_النشر_والربط.md   خطوات الرفع والربط بالتفصيل
```
